# Minifolio

디자이너를 위한 미니 포트폴리오 사이트 생성기입니다.
배경, 타이틀, 이미지 10장, 사용 툴, 프로젝트별 상세 정보만 입력하면 움직이는 그라데이션 배경 위에 포트폴리오가 만들어지고, **HTML 파일 하나**로 내보낼 수 있습니다.

## 주요 기능

- **배경**: 그라데이션 프리셋 7종 + 커스텀 색(바탕 1 + 색 4), 움직임 속도, 필름 그레인
- **타이틀**: 포트폴리오 타이틀과 서브카피
- **이미지 10장**: 클릭·여러 장 업로드·드래그&드롭, 칸끼리 드래그로 순서 변경
- **프로젝트 상세**: 썸네일을 누르면 이미지 옆에 프로젝트명, 클라이언트·연도, 소개, 성과(Impact), 역할(Role), 담당 업무(What I did)가 열림
- **사용 툴**: 이름만 입력하면 30여 개 툴은 로고 자동 표시(브랜드 컬러/모노), 그 외는 로고 파일 업로드 또는 이니셜 배지
- **미리보기**: Desktop / Mobile 전환, 미리보기만 보기
- **자동 저장**: 브라우저(IndexedDB)에 작업 내용 저장
- **내보내기**: 이미지·폰트 링크·애니메이션이 모두 들어간 단일 HTML 파일

## 사용법

1. `index.html`을 브라우저로 엽니다. (서버 없이 파일을 더블클릭해도 동작합니다.)
2. 왼쪽 설정에서 내용을 채웁니다.
3. 오른쪽 위 **HTML 내보내기**를 누르면 포트폴리오 HTML 파일이 저장됩니다.
4. 저장된 파일을 GitHub Pages, Netlify 등 아무 정적 호스팅에 올리면 바로 사이트가 됩니다.

## GitHub Pages로 이 툴 배포하기

1. 새 저장소를 만들고 `index.html`, `README.md`를 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 지정합니다.
3. 잠시 후 `https://<아이디>.github.io/<저장소명>/` 에서 툴이 열립니다.

> 내보낸 포트폴리오도 같은 방법으로 올릴 수 있습니다. 파일 이름을 `index.html`로 바꿔 새 저장소에 올리면 됩니다.

## 참고

- 툴 로고는 [Simple Icons](https://simpleicons.org) (CC0, v16.34.0)에서 자주 쓰는 툴만 골라 내장했습니다. 각 로고는 해당 브랜드의 상표이며, 사용 시 각 브랜드 가이드를 따르세요. Adobe 제품 로고는 Simple Icons에 포함되어 있지 않습니다.
- 폰트: Geist, Geist Mono, IBM Plex Sans KR (Google Fonts)
- 자동 저장은 사용하는 브라우저에만 남습니다. 브라우저 데이터를 지우면 함께 사라집니다.
- 외부 라이브러리 없이 HTML·CSS·JavaScript 한 파일로 동작합니다.
