사용 가이드

  1. 배경 고르기프리셋 중 하나를 고르거나 Custom에서 색을 직접 정해요. 속도와 필름 그레인도 여기서 조절해요.
  2. 타이틀 쓰기포폴 제목과 소개 문장을 쓰고, 제목 폰트를 골라요. 목록에 없는 구글 폰트도 이름으로 넣을 수 있어요.
  3. 이미지 올리기빈 칸을 누르거나 파일을 끌어다 놓아요. 최대 10장이고, 칸끼리 드래그하면 순서가 바뀌어요. 배치는 장수에 맞춰 자동으로 짜여요.
  4. 프로젝트 정보 (선택)올린 이미지를 누르고 ‘프로젝트 정보 넣기’를 누르면 프로젝트명과 내용을 붙일 수 있어요. 안 넣으면 이미지만 크게 보여요.
  5. 사용 툴 · 연락처툴 이름을 쓰면 로고가 자동으로 붙어요. 이메일과 링크를 넣으면 포폴 맨 아래에 연락처가 생겨요.
  6. 미리보기 확인상단의 Desktop / Mobile로 PC와 폰에서 어떻게 보이는지 확인해요. 미리보기에만 적용되고 결과물에는 영향이 없어요.
  7. 내보내기웹사이트(HTML), PDF, Word 중 골라 저장해요. HTML은 GitHub Pages나 Netlify에 그대로 올리면 바로 사이트가 돼요.

작업은 이 브라우저에 자동 저장돼요. 다른 컴퓨터에서 이어 하려면 내보내기 창의 ‘백업 저장’으로 파일을 받아 두고 ‘불러오기’로 여세요.
